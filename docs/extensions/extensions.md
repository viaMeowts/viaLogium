# Extensions

ViaLogium extensions allow for additional functionality to be added to ViaLogium via another mod

## Install

1. Install ViaLogium
2. Install the extension of your choice in your mods folder
3. Run your server and adjust the config as needed. The extension should provide information on how to configure it

## Available extensions
- [ViaLogium Databases](https://www.curseforge.com/minecraft/mc-mods/vialogium-databases) - Adds support for MySQL and H2

## Features possible via extensions

- Changing the type of database used by ViaLogium
- Adding custom commands
- Adding configuration options to the existing [config file](../config.md)
