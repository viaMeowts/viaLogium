# viaLogium — пользовательский гайд для Discord

Ниже текст в формате, который можно целиком вставить в Discord.

---

## 📘 viaLogium: быстрый гайд для игроков и модераторов

viaLogium — это история действий в мире: кто, что, где и когда сделал.

### ⚡ Базовый принцип
- Все команды начинаются с `/vl`.
- Для просмотра логов используйте `inspect`, `search`, `near`, `page`.
- Для отката/возврата действий используйте `rollback`, `preview`, `restore`.

---

## 1) Быстрый старт

### Просмотреть лог по блоку
- `/vl inspect` — включить режим инспекта
- ЛКМ/ПКМ по блоку — показать историю действий по нему
- `/vl inspect off` — выключить режим

Короткий алиас:
- `/vl i` = `/vl inspect`

### Поиск по параметрам
- `/vl search <параметры>`
- Пример: `/vl search action:block-break range:5`

### Страницы
- `/vl page 2` — перейти на 2-ю страницу последнего поиска

---

## 2) Полезные команды

### Поиск рядом
- `/vl near`
Показывает действия рядом с вами (радиус задаёт сервер).

### Откат
- `/vl rollback <параметры>`
Откатывает найденные действия.

### Предпросмотр отката (рекомендуется)
- `/vl preview rollback <параметры>`
- `/vl preview apply` — применить
- `/vl preview cancel` — отменить

### Возврат после отката
- `/vl restore <параметры>`

### Служебные
- `/vl status` — статус мода/очереди БД
- `/vl player <ник>` — история входов игрока
- `/vl tp <мир> <x> <y> <z>` — телепорт к координатам

---

## 3) Параметры поиска

Параметры пишутся в формате `ключ:значение` через пробел.

### Основные
- `action:<тип>` — тип действия
- `source:<источник>` — кто/что сделал
- `object:<id>` — объект (блок/предмет/сущность)
- `world:<измерение>` — мир
- `range:<число>` — радиус вокруг вас
- `before:<время>` — до указанного времени
- `after:<время>` — после указанного времени
- `rolledback:true|false` — фильтр по откатанным действиям

### Отрицание
Можно исключать значения через `!`:
- `source:!PlayerName`
- `action:!block-place`

---

## 4) Формат времени

В `before/after` используйте суффиксы:
- `s` — секунды
- `m` — минуты
- `h` — часы
- `d` — дни
- `w` — недели

Примеры:
- `after:30m`
- `after:2h30m`
- `before:1d`

---

## 5) Готовые примеры

### Кто ломал рядом за последний час
`/vl search action:block-break range:10 after:1h`

### Кто клал/забирал вещи в зоне
`/vl search action:item-insert range:8 after:2h`
`/vl search action:item-remove range:8 after:2h`

### Проверить конкретного игрока
`/vl search source:PlayerName after:12h`

### Проверить только неоткаченные действия
`/vl search source:PlayerName after:12h rolledback:false`

### Безопасный откат (через preview)
1. `/vl preview rollback source:PlayerName after:30m range:20`
2. Проверить результат
3. `/vl preview apply`

---

## 6) Практика и безопасность

- Всегда сначала делайте `preview rollback`, потом `apply`.
- Делайте максимально узкие фильтры: `source + after + range`.
- Если результатов много — уточняйте поиск, а не откатывайте «широко».
- После поиска листайте страницы через `/vl page <номер>`.

---

## 7) Частые ошибки

- **"No cached search"**
  - Сначала выполните `/vl search ...`, потом `/vl page ...`.

- **"No results"**
  - Расширьте `range` или увеличьте интервал `after`.

- **Не хватает прав**
  - Обратитесь к администрации для выдачи permission-узлов.
